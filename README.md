# Mareli Embragues – Landing Page

Landing dark racing para Mareli Embragues (Mendoza).

## Cómo ver la página

Abrí `index.html` en el navegador o usá un servidor local (por ejemplo Live Server).

## Logo

Colocá la imagen del logo en:

**`assets/logo-mareli.png`**

Si tu logo tiene otro nombre, renombralo a `logo-mareli.png` o cambiá la ruta en `index.html` (atributo `src` del `<img>` del hero).

## Mapa de Google

El iframe del mapa usa la dirección **Gobernador Videla 2315, San José, Guaymallén, Mendoza**. Para un mapa más exacto o estilo oscuro personalizado, podés reemplazar el `src` del iframe por el código que te da Google Maps (Compartir → Insertar un mapa).

## Estructura

- **index.html** – Estructura y contenido
- **styles.css** – Estilos, animaciones y responsive
- **script.js** – Reveal on scroll (animaciones al bajar)
- **assets/** – Carpeta para el logo y, si querés, más imágenes
